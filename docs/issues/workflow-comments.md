# Issue comments

When agents may post on epic/task/defect/feedback issues. Status transitions: [workflow.md](workflow.md). Cap: [workflow-comment-cap.md](workflow-comment-cap.md). Feedback tracking: [feedback.md](feedback.md).

Comment only when something material happened: a status transition, pass/fail/clarify with new substance, new deliverables evidence, or a **blocker discovered for the first time** on that issue. One comment per distinct blocker; later re-runs that find the same blocker stay silent. Never post “still waiting,” “nothing to report,” or unchanged-status noise. Chat/dispatch may note a silent no-op. Be terse — no more than necessary.
