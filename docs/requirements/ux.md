# UX requirement notes

Raw notes until a UX capture run consumes them. Not specs.

- the user should be able to configure toggling on/off different types of hints in the settings; toggles are persisted. — target: `specs/ux/screens/settings.md`
- single-line and multi-line fill hints show as overlays (not writing marks); overlay colour differs from the line-level fillable shade. — target: `specs/ux/screens/puzzle.md`
- line level fillable hint: with fill active, tap a tile → shade max legal run containing the tap in a lighter colour, or no shade if none. — target: `specs/ux/screens/puzzle.md`
- hint-free star on the upper left corner of the solved puzzle tile in the gallery when hint-free status is true. — target: `specs/ux/screens/gallery.md`
