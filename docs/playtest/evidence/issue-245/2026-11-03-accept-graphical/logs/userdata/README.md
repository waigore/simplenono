# Run scratch user data

`userdata/` in this folder is the run's own Godot user directory (`HOME` on macOS, `XDG_DATA_HOME` on Linux),
so the capture probe never touched the runner's real player progress. It holds only the progress save this run
wrote and the engine's own cache copies, and it is regenerated by [`reproduce.md`](../../reproduce.md):

```bash
export HOME="$PWD/docs/playtest/evidence/issue-245/2026-11-03-accept-graphical/logs/userdata/home"
```

It is kept out of git so the evidence PR stays small (see [`.gitignore`](.gitignore)).
