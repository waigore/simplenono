# Run scratch user data

`userdata/` in this folder is the run's own Godot user directory (`XDG_DATA_HOME`), so the capture probe never
touched the runner's real `~/.local/share/simplenono`. It holds only the progress save this run wrote and the
engine's import-cache copies, and it is regenerated by [`reproduce.md`](../../reproduce.md):

```bash
export XDG_DATA_HOME="$PWD/docs/playtest/evidence/issue-232/2026-11-02-accept-graphical/logs/userdata"
```

It is kept out of git so the evidence PR stays small.
