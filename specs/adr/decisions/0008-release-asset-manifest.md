# ADR-0008: Release asset manifest build output

- **Status**: Accepted
- **Date**: 2026-11-04
- **Category**: Integration
- **Supersedes**: None
- **Informed by**: Offline play after install on five definition platforms ([`definition.md`](../../definition/definition.md)); one reader, one generator, one source of truth ([`ACC.A1`–`A3`](../../assets/access.md)); manifest, roots, resolver ([ADR-0003](0003-catalog-asset-roots.md)); generator ([ADR-0006](0006-asset-manifest-generator.md)); unpinned engine ([ADR-0001](0001-godot-gdscript.md)).

## Context

[ADR-0003](0003-catalog-asset-roots.md) puts the manifest at `assets/manifest.json`, outside `res://` (`game/`), read only by [`CMP-shell`](../../technical/components/shell.md). An export packs only `res://`, so that path reaches nothing and no ID resolves. [`asset-access`](../../technical/asset-access.md) O1 reads "no generated build outputs", so an in-build file needs this decision.

## Purpose

How the manifest reaches an exported release build and who reads it there. In scope: mechanism, single `res://` destination, sources, dev behavior. Out: generator ([ADR-0006](0006-asset-manifest-generator.md)), roots ([ADR-0003](0003-catalog-asset-roots.md)), presets, packaging.

## Decision

- **Mechanism**: the release export script copies the committed root manifest to `res://release/asset_manifest.json`, the one destination, before exporting; every release preset's `include_filter` names exactly that file. Godot's importer maps `res://` paths to imported resources; no script of ours does.
- **Sources**: the committed `assets/manifest.json`, regenerated only by `asset_manifest.py` ([ADR-0006](0006-asset-manifest-generator.md)); not the catalog, not a second derivation.
- **Generated by export only**: written by the export script, never committed (`.gitignore` excludes `build/release/`), never edited. Two hand-kept copies, restating the root manifest, and a second generator are forbidden.
- **One reader**: [`CMP-shell`](../../technical/components/shell.md) only. A release build reads `res://release/asset_manifest.json`; the editor and tests read the committed root manifest. The resolver picks by whether that root manifest is reachable: present, it is the dev read; absent, the packed copy is the only read. An export packs only `res://`, so `res://../` never resolves there, and `asset_resolver.gd` alone names it.

## Reasoning

1. **Offline install** ([`definition.md`](../../definition/definition.md)): the pack carries its manifest; resolving stays a local read.
2. **One source of truth** ([`ACC.A2`](../../assets/access.md)): the bytes are the committed file, so the [ADR-0006](0006-asset-manifest-generator.md) drift check still guards what ships.
3. **No engine coupling** ([ADR-0001](0001-godot-gdscript.md)): a copy and one filter line; a template bump edits no preset.
4. **Loud failure** ([`ACC.A3`](../../assets/access.md)): a missing or stale copy fails the resolver and the release check. Cost: one generated file under `res://`; a dev run without it fails loudly, never falls back.

## Rejected alternatives

Shipped as-is, a committed second copy, a second generator, a runtime `res://../` read, and an exporter plugin all lost. Table: [`rejected.md`](0008-release-asset-manifest/rejected.md).
